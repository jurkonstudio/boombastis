Hash Generator

MD5, SHA-1, SHA-256, SHA-384 and SHA-512 from text or a file.

About this tool

A hash is a fixed-length fingerprint of data. This hash generator computes MD5, SHA-1, SHA-256, SHA-384 and SHA-512 from text or from a file, which is handy for verifying downloads, comparing files and checking integrity. Everything is computed locally and your data is never uploaded.

How it works

SHA algorithms run through the Web Crypto API built into your browser, and MD5 uses a small built-in implementation. The same input always gives the same hash, and changing even one character changes the result completely. Hashes update as you type, and you can hash a file instead of text.

How to use

  1. Type text, or choose a file to hash.
  2. Copy the hash you need.
  3. Compare it with a published checksum to confirm a download is intact.

Frequently asked questions

Which hash should I use?

Use SHA-256 or SHA-512 for integrity checks. MD5 and SHA-1 have known collision attacks, so keep them for non-security checksums such as detecting accidental corruption.

Can a hash be reversed to get the original text?

Not directly. But short or common inputs can be found by trying many guesses or with precomputed tables, which is why plain hashes are not suitable for protecting passwords.

Is hashing the same as encryption?

No. Encryption can be undone with a key, while hashing is one-way. Hashes are used to check that data has not changed, not to hide it.

How do I verify a downloaded file?

Hash the file here and compare the result with the checksum published by the software’s authors. If they match exactly, the file was not altered or corrupted.

Should I use these hashes to store passwords?

No. Store passwords with a slow, salted algorithm designed for the job, such as Argon2, bcrypt or scrypt, not with MD5 or SHA-256 alone.

Why is hashing a very large file slow?

The tool reads the whole file into memory before hashing it. Very large files can take a while or use a lot of memory on small devices.
