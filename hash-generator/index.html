Hash Generator

MD5, SHA-1, SHA-256, SHA-384 and SHA-512 from text or a file.

How it works

Hashes are computed locally: SHA algorithms use your browser’s built-in Web Crypto API, and MD5 uses a small built-in implementation. Your text and files are never uploaded.

How to use

  1. Type text, or pick a file to hash.
  2. Copy the hash you need.
  3. Compare it with a published checksum to verify a download.

Which hash should I use?

Use SHA-256 or SHA-512 for integrity checks. MD5 and SHA-1 are broken for security purposes and should only be used for non-security checksums. Never use a plain hash to store passwords.
