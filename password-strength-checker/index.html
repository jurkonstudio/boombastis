How it works

The checker estimates entropy from length and character variety, then lowers the score for common passwords, repeated characters and keyboard or alphabet sequences. The crack time assumes an offline attack at 10 billion guesses per second. It is an estimate, not a guarantee.

How to use

  1. Type a password to test, or paste one.
  2. Read the score and the tips.
  3. Replace weak passwords, ideally with a generated one.

Is it safe to type my real password?

The password never leaves this page: no request is made and nothing is stored. Still, as a habit, test a similar password rather than one you use today.
