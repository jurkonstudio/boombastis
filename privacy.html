Kebijakan Privasi

Terakhir diperbarui: 1 November 2026

Halaman ini menjelaskan data apa yang kami simpan dan bagaimana data itu dilindungi.

Data yang kami simpan

  • Akun: nama, email, nomor WhatsApp, dan password (disimpan terenkripsi oleh Supabase Auth).
  • Pesan: isi, nomor tujuan atau pengirim, dan status SMS yang lewat HP gateway-mu.
  • Perangkat dan API key: nama perangkat, waktu terakhir online, dan hash API key (key asli tidak disimpan).
  • Pembayaran: paket, nominal, dan status pesanan.

Siapa yang dapat melihat

Setiap akun hanya dapat membaca datanya sendiri. Admin tidak dapat membaca isi SMS; admin hanya melihat ringkasan seperti paket, kuota terpakai, dan jumlah SMS terkirim, serta data kontak untuk keperluan pembayaran dan bantuan.

Penyimpanan

Data disimpan di Supabase. Kami tidak menjual data kepada pihak ketiga.

Hak kamu

Kamu dapat meminta penghapusan akun dan datamu lewat kontak di bawah.

Cookie dan penyimpanan lokal

Panel memakai penyimpanan browser untuk menjaga sesi login. Kami tidak memasang pelacak iklan.

Kontak untuk pertanyaan dan laporan: lihat kontak di halaman utama.
