Fonctionnalités

Tout pour gérer vos SMS

Envoi depuis le panneau

Rédigez dans le navigateur ; le message est mis en file et envoyé via la SIM de votre téléphone passerelle, avec un statut clair à chaque étape.

Boîte de réception en temps réel

Les SMS reçus sur le téléphone apparaissent aussitôt dans le panneau, avec expéditeur et heure.

Réponse automatique

Définissez des règles par mot-clé, avec délai par expéditeur et plafond quotidien.

Suivi des appareils

Sachez si votre téléphone passerelle est en ligne grâce à un signal de vie chaque minute.

Résiste aux coupures

Les résultats et SMS reçus sont stockés localement puis renvoyés au retour d'internet, sans doublon.

Vos données, votre contrôle

Les données de chaque client sont séparées et lisibles par leur seul propriétaire. Les administrateurs ne peuvent pas ouvrir le contenu des SMS.

Fonctionnement

Trois étapes, sans serveur à gérer

Écrivez dans le panneau

Le message entre dans la file d'envoi Supabase avec le statut en attente.

Le téléphone récupère et envoie

L'appli Android consulte régulièrement la file, envoie via la SIM et rapporte le résultat.

Suivez le résultat

Les statuts envoyé, échec et réponse s'affichent en temps réel dans le panneau.

Sécurité

Fermé dès la conception

  • Données séparées par compte. Chaque client ne voit que ses propres messages.
  • Contrôle d'accès dans la base. Le Row Level Security est actif ; les appareils n'appellent que les fonctions autorisées.
  • Aucune clé secrète dans le code. Le panneau utilise la clé anon publique, jamais la service role.
  • Limites de réponse automatique. Le délai par expéditeur et le plafond quotidien évitent les envois massifs accidentels.

Questions fréquentes

Qu'est-ce que Boombastis ?

Boombastis est un service de passerelle SMS. Vous installez une appli Android sur votre téléphone, puis envoyez et recevez des SMS depuis le navigateur ou par API. Les messages partent de la SIM de votre téléphone.

Les SMS utilisent-ils mon crédit ?

Oui. Les SMS partent de la SIM de votre téléphone passerelle et consomment donc son crédit ou son forfait SMS. Le prix du forfait couvre le panneau, le quota, la file et le suivi.

Quel téléphone faut-il ?

Un téléphone Android avec SIM active et connexion internet. L'appli se télécharge en APK depuis ce site, pas depuis Google Play.

Puis-je envoyer des SMS depuis mon site ou mon appli ?

Oui. Créez une clé API dans le panneau et envoyez des requêtes HTTPS depuis votre serveur. Les SMS partent toujours via votre téléphone passerelle et comptent dans le quota.

L'administrateur peut-il lire mes SMS ?

Non. Les données de chaque compte sont séparées et lisibles par leur seul propriétaire. L'administrateur ne voit que des résumés, comme le nombre de SMS envoyés.
