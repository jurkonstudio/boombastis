About this tool

Every browser sends a text string called the user agent with each request. This page shows yours, along with the browser, operating system, device type, screen size, language and time zone that websites can see. It is useful for bug reports, for testing responsive layouts and for checking what your browser reveals.

How it works

All the values are read from your own browser using standard web APIs. Nothing is sent to Boombastis or anyone else. The summary is derived from the user agent string, while the details come from separate browser properties such as screen size, language and hardware information.

How to use

  1. Open the page to see your summary and user agent string.
  2. Use the copy button to include the string in a bug report.
  3. Check the details to see what a website could learn about your browser.

Frequently asked questions

What is a user agent?

A line of text your browser sends with every request, describing the browser, its engine and the operating system. Websites use it to adapt content and to detect browsers and devices.

Why does my Chrome user agent show an old Android or Windows version?

Chrome reduces the detail in its user agent string for privacy, so operating system and minor version numbers are generalized. The string is intentionally less precise than it used to be.

Can websites identify me from this information?

Not by the user agent alone, but combined with screen size, language, time zone and other signals it can help build a browser fingerprint. Privacy-focused browsers limit or randomize some of these values.

How can I change my user agent?

Your browser’s developer tools include a device emulation mode that changes the user agent and screen size for testing. Some extensions can also change it, but doing so can break sites.

Does this page send my information anywhere?

No. The data is read locally and shown on the page. Nothing is stored or transmitted by Boombastis.
