About this tool

URLs can only contain a limited set of characters. Spaces, accents, emoji and symbols like &, = and # must be percent-encoded, for example a space becomes %20. This tool encodes and decodes them correctly with full UTF-8 support.

Leave the box unticked to encode a single value such as a search term. Tick Keep a whole URL when encoding an entire address so the structure stays intact.

How to use

  1. Paste text or a link into the box.
  2. Press Encode to make it URL-safe, or Decode to read an encoded value.
  3. Press Show URL parts to split a full link into host, path and query parameters.
  4. Copy the result.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

What is the difference between the two modes?

By default every special character is encoded, which is right for a single value. With Keep a whole URL, characters that give a URL its structure (: / ? # & =) are left alone.

Why does decoding fail?

A % must be followed by two hex digits. Text like 100% sure is not valid percent-encoding.

Does it support emoji and accents?

Yes. Text is converted to UTF-8 first.
