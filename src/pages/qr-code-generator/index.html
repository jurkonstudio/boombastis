About this tool

This free QR code generator turns a link, Wi-Fi text, email address or any short message into a QR code you can download as a PNG. The code is drawn on your device, there is no account, no watermark and no tracking, and the codes never expire because they are static.

How it works

Your text is encoded into a grid of modules, with a quiet border added around it so scanners can find the edges. The error correction level controls how much of the code can be damaged or covered and still scan. Higher levels add redundancy, which makes the code denser.

How to use

  1. Type or paste a link or text.
  2. Choose the PNG size and the error correction level.
  3. Download the PNG and test it with your phone before printing.

Frequently asked questions

Do these QR codes expire?

No. The code contains your text directly, so it works as long as the link or information inside it is still valid. There is no redirect service that could be switched off.

Which error correction level should I use?

Use M for most screens and prints. Use Q or H if the code will be printed small, may get scuffed, or will carry a logo on top. L produces the simplest code and suits clean digital use. Roughly, L, M, Q and H can recover about 7, 15, 25 and 30 percent of damage.

How big should I print a QR code?

Keep it at least about 2 cm (0.8 in) wide, and larger for posters viewed from a distance. A good rule is one tenth of the scanning distance. Always test the printed result.

Why is my QR code so dense?

The more text you encode, the more modules are needed. Use a shorter link, drop unnecessary parameters, or raise the PNG size so each module stays sharp.

Yes. The generated image is yours to use on products, flyers or menus. The Boombastis name and logo are separate and covered by the brand license.
