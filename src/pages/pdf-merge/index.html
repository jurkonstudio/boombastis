About this tool

Merging joins several PDFs into a single file, which is handy for sending one attachment, combining scanned pages, or building a report from separate parts. Pages keep their original size, text and quality because they are copied, not re-rendered.

Files are merged in the order shown in the list. Use the arrow buttons to move a file up or down, or the cross to remove it.

How to use

  1. Tap the box and choose two or more PDF files, or drag them in.
  2. Check the order in the list. Use ↑ and ↓ to move a file, ✕ to remove it.
  3. Press Merge PDF, then Download.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

Is there a file size or page limit?

There is no limit set by this site. The limit is your device memory, so very large files (several hundred MB) may be slow on phones.

Does merging reduce quality?

No. Pages are copied as they are, so text stays selectable and images keep their quality.

Why does a file fail to open?

Password-protected or damaged PDFs cannot be read. Remove the password first, then try again.
