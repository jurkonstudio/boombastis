About this tool

Large PDFs are hard to email and slow to upload. This tool rebuilds the document with lighter page images, which shrinks scans and photo-heavy PDFs a lot. The result is checked, and you are warned if it is not smaller than your original.

Because it never leaves your device, you can safely shrink private documents such as IDs, contracts and invoices.

How to use

  1. Choose the PDF.
  2. Pick a method. Use Smaller file for scans and photos. Use Keep text for text-only PDFs.
  3. Pick a level. Balanced is a good start; try Strong if it is still too big.
  4. Press Compress PDF and download.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

Why is my PDF not smaller?

Text-only PDFs are already compact. Use Smaller file mode for scans and photos, which gives the biggest savings.

Can I still select text after compressing?

Only in Keep text mode. Smaller file mode turns pages into images, so text is no longer selectable.

Which level should I choose?

Balanced reads well on screen and in print. Use Strong when you need the smallest possible file and can accept softer images.
