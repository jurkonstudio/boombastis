EXIF Remover

Strip GPS location and camera data from photos. Pixels stay untouched.

Keeps one tiny orientation flag so phone photos do not turn sideways. Applies to the next files you add.

About this tool

Every photo you take carries a hidden label. It can include the exact GPS spot where you stood, the phone model and its serial number, the time to the second, and the editing app you used. Share the original file and all of that goes along with it. This EXIF remover cuts that data out and leaves the picture itself exactly as it was.

How it works

Image files are made of blocks. The picture lives in one block and the metadata in others. This tool reads your file, copies the picture blocks as they are, and drops the metadata blocks, so there is no re-compression and no quality loss. Afterwards it scans the new file again and tells you whether anything is left. Click "What was in this file" on a result to see what was removed.

How to use

  1. Drop or choose one or more JPG, PNG or WebP photos.
  2. Check the result list: photos that contained a GPS location are flagged.
  3. Download each clean file, or all of them in one ZIP.

Frequently asked questions

Is my photo uploaded anywhere?

No. The file is read and rewritten inside your browser, so your photos never leave your device and nothing is stored on a server. You can even switch off your connection after the page has loaded and it will still work.

What exactly gets removed?

For JPEG: EXIF (camera model, lens, serial number, date, GPS location), XMP, IPTC and Photoshop data, comments, and any extra data hidden after the image, which some phones use for depth maps or short video clips. For PNG: EXIF, text chunks (some AI image tools store the full prompt there) and the modified time. For WebP: EXIF and XMP. The colour profile is kept so colours look the same.

Does it reduce image quality?

No. The picture data is copied byte for byte and only the metadata blocks are cut out, so the pixels are identical to the original. This is different from re-saving or compressing the image, which re-encodes it and can add artifacts.

Why does it keep the rotation by default?

Many phones save photos sideways and use a small orientation flag to turn them upright. If that flag is deleted, some photos show up rotated. The tool keeps only that single flag, which holds no personal information. Untick the option if you want every last tag removed.

Which file types are supported?

JPG, PNG and WebP. HEIC, GIF, TIFF and RAW files are not supported yet. If your browser can open them, the Image Compressor can convert them to JPEG or WebP, which also drops the metadata, but it re-encodes the picture.

Does removing metadata make a photo anonymous?

It removes the hidden data, but not what is visible in the picture, such as faces, street signs or a recognisable view. The file name is also kept except for a -clean suffix, so rename it if the name is personal. After cleaning, the tool scans the new file again and tells you if anything is left.
