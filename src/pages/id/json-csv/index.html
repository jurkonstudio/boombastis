Konverter JSON ke CSV dan CSV ke JSON

Tempel data, pilih arah konversi, salin atau unduh hasil.

Tentang alat ini

JSON dipakai oleh API dan aplikasi web, sedangkan CSV dibuka di Excel atau Google Sheets. Alat ini menjembatani keduanya. Tempel JSON berupa daftar objek untuk mendapatkan CSV, atau tempel CSV dengan baris judul untuk mendapatkan JSON.

Objek bersarang diratakan menjadi kolom dengan notasi titik (misalnya alamat.kota), dan larik disimpan sebagai teks JSON. Pilih titik koma sebagai pemisah bila Excel Anda berbahasa Indonesia, karena koma dipakai sebagai desimal. Kolom yang berisi koma, tanda kutip, atau baris baru dikutip dengan benar. Semua proses ada di browser Anda.

Cara memakai

  1. Tempel data JSON atau CSV.
  2. Pilih pemisah CSV yang sesuai.
  3. Klik arah konversi, lalu salin atau unduh.

Pertanyaan yang sering diajukan

Kenapa Excel saya menampilkan semua data di satu kolom?

Excel berbahasa Indonesia biasanya memakai titik koma sebagai pemisah. Pilih “Titik koma” lalu konversi ulang.

Bagaimana JSON bersarang diubah?

Objek diratakan menjadi kolom bertitik, misalnya a.b. Larik ditulis sebagai teks JSON dalam satu sel.

Apa maksud opsi ubah angka?

Nilai seperti 30 atau true menjadi angka atau boolean di JSON, bukan teks. Matikan jika Anda ingin semua nilai tetap berupa teks, misalnya nomor telepon dengan angka 0 di depan.

Apakah ada batas ukuran data?

Beberapa megabyte aman di kebanyakan perangkat. Data yang sangat besar bisa memperlambat browser.

Apakah data saya diunggah?

Tidak. Konversi berjalan di browser Anda.
