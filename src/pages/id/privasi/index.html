Ringkasan

Boombastis tidak meminta Anda membuat akun dan tidak memakai analitik. Situs ini sendiri tidak memasang cookie, tetapi menampilkan iklan lewat Google AdSense yang dapat memasang cookie sendiri (lihat daftar pihak ketiga di bawah). File, kata sandi, dan teks yang Anda masukkan diproses di browser dan tidak dikirim kepada kami.

Alat yang tetap di perangkat Anda

Image Compressor, QR Code Generator, Password Generator, Password Strength, Word Counter, Hash Generator, Browser Info, JSON Formatter, Base64, Case Converter, dan alat berbahasa Indonesia (Terbilang, Pace, THR, Umur, Kompres Foto, JSON/CSV) bekerja secara lokal. Apa pun yang Anda ketik atau pilih tidak meninggalkan perangkat. Instagram Non-Followers Checker membaca file ekspor yang Anda pilih di dalam browser; file tidak diunggah dan tidak ada yang disimpan.

Permintaan ke pihak ketiga

  • IP & DNS Checker: meminta api64.ipify.org dan ipwho.is untuk alamat IP publik, negara, dan ISP Anda, serta mengirim nama domain yang Anda cari ke Cloudflare DNS (cloudflare-dns.com) dan Google DNS (dns.google). Layanan itu melihat alamat IP dan domain yang Anda cari, sesuai kebijakan privasi masing-masing.
  • QR Code Generator: memuat pustaka QR dari cdnjs.cloudflare.com. Cloudflare menerima permintaan web biasa (alamat IP, detail browser) saat halaman dimuat.
  • Iklan (Google AdSense): halaman memuat skrip dari pagead2.googlesyndication.com untuk menampilkan iklan. Google dan mitranya dapat memakai cookie dan teknologi serupa untuk menayangkan dan mengukur iklan, termasuk iklan berdasarkan kunjungan Anda sebelumnya ke situs ini dan situs lain, dan menerima alamat IP serta detail browser Anda. Anda dapat mengatur iklan yang dipersonalisasi di adssettings.google.com dan membaca cara Google memakai data dari situs mitra di policies.google.com/technologies/partner-sites.
  • Hosting: situs disajikan oleh GitHub Pages. GitHub dapat mencatat alamat IP pengunjung sesuai kebijakannya sendiri. Kami tidak menerima data log tersebut.

Papan peringkat Tes Kecepatan Mengetik

Tes mengetik berjalan di browser Anda. Hanya jika Anda menekan Submit score, nama yang Anda ketik, kecepatan, akurasi, durasi tes, dan waktu pengiriman dikirim ke database kami (Supabase) dan ditampilkan di papan peringkat publik. Jangan memakai nama asli atau data pribadi sebagai nama papan peringkat. Kami tidak menyimpan akun, email, atau alamat IP untuk fitur ini. Untuk menghapus entri, hubungi kami lewat halaman Kontak.

Data yang disimpan di browser

Agar bisa dipakai offline, situs menyimpan file miliknya sendiri di cache browser lewat service worker. Isinya tidak berisi data pribadi. Anda bisa menghapusnya kapan saja dengan menghapus data situs {{HOST}} di pengaturan browser.
