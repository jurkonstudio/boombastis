About this tool

Regular expressions describe patterns in text, such as emails, dates or codes. This tester uses the JavaScript regex engine of your browser, shows matches highlighted as you type, lists each match with its position and capture groups, and previews a replacement.

Very complex patterns on long text can make any regex engine slow. If the page freezes, simplify the pattern.

How to use

  1. Type your pattern without the slashes.
  2. Choose flags: g finds all matches, i ignores case.
  3. Paste text to test. Matches are highlighted and listed.
  4. Optionally type a replacement to preview the result.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

Which regex flavor is this?

JavaScript (ECMAScript). Most basics work the same in other languages, but some features such as lookbehind or named groups differ between engines.

What do the flags mean?

g finds all matches, i ignores case, m makes ^ and $ match each line, s lets . match new lines, u enables full Unicode.

How do I use capture groups in replacement?

Write $1, $2 and so on, or $<name> for named groups.
