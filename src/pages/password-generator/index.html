Password Generator

Strong random passwords, created on your device.

About this tool

A strong password is long, random and unique to each account. This password generator creates random passwords with your browser’s cryptographically secure random number generator, so every character is chosen unpredictably. Nothing is sent to a server and nothing is saved.

How it works

You choose a length from 8 to 64 characters and which character sets to include. The generator draws random values from the secure source built into your browser and discards values that would bias the result, so each character is equally likely. A fresh password is created every time you change a setting.

How to use

  1. Choose the length and character types.
  2. Press Generate until you like the result.
  3. Copy it into your password manager and use it for one account only.

Frequently asked questions

How long should a password be?

Aim for at least 16 characters for important accounts. Length matters more than complexity: every extra character multiplies the number of guesses an attacker needs.

Is a browser-based password generator safe?

This one uses the Web Crypto random generator built into your browser, the same source used for encryption keys. The password is created on your device and is never transmitted, logged or stored.

Should I include symbols?

Symbols add variety, but some sites reject certain characters. If a site refuses a password, turn symbols off and increase the length instead.

Why use a different password for every site?

When one site is breached, attackers try the leaked password on other services. A unique password per account limits the damage to a single site.

Where should I store generated passwords?

In a reputable password manager. Also turn on two-factor authentication for important accounts, since a strong password alone cannot stop phishing.

Can I use a passphrase instead?

Yes. Several unrelated random words are easy to remember and can be very strong when the words are chosen randomly. This tool generates character passwords, which are better suited to a password manager.
