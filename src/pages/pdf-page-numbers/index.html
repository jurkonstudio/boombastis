About this tool

Long documents are easier to read, print and refer to when the pages are numbered. This tool stamps a number on every page, in the corner you choose, and works even on pages that are rotated.

Choose Page 1 of 10 style to show the total, set a start number for a document that continues from another one, and skip the cover page if you want.

How to use

  1. Choose the PDF.
  2. Pick the position and format. Change the start number if needed.
  3. Tick Do not number the first page to leave the cover clean.
  4. Press Add page numbers and download.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

Can numbering start from a number other than 1?

Yes. Change Start at. The total in the Page X of Y style is adjusted to match.

Can I skip the cover page?

Yes. Tick the cover page option. Numbering then starts on page 2 with the number you picked for it.

Which fonts are used?

A clean standard sans-serif font (Helvetica), so numbers look the same on every device.
