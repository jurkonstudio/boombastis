Text Case Converter

Convert text between common letter cases and code styles.

About this tool

Retyping text just to change its capitalisation is slow. This converter handles common cases in one click: uppercase, lowercase, title case, sentence case, and the naming styles programmers use such as camelCase, snake_case and kebab-case.

The URL slug option also removes accents and punctuation, which is useful for blog post addresses and file names. Nothing you type leaves your browser.

How to use

  1. Paste your text.
  2. Click the case you want.
  3. Copy the result.

Frequently asked questions

What is the difference between title case and sentence case?

Title case capitalises every word. Sentence case capitalises only the first letter of each sentence.

What is a slug?

A short, lowercase, hyphen-separated version of a title used in web addresses, such as my-first-post.

Are accented letters kept?

They are kept for the basic cases and converted to plain letters in the slug option.

Does camelCase start with a lowercase letter?

Yes. The first word is lowercase and each following word starts with a capital, with no separators.

Is my text stored?

No. It stays in your browser tab only.
