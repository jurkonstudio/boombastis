JSON Formatter

Paste JSON to format, validate or minify it.

About this tool

Developers, analysts and students often receive JSON as one long unreadable line. This formatter indents it so the structure is clear, checks that it is valid and can also compress it back into one compact line. Everything happens in your browser, so API responses and config files stay on your device.

The tool uses the browser's built-in JSON parser. If your text is valid it is re-printed with two-space indentation (or with all whitespace removed when you minify). If it is not valid, you get the parser's error message so you can find the problem.

How to use

  1. Paste your JSON.
  2. Press Format to indent it, or Minify to compress it.
  3. Copy the result.

Frequently asked questions

Is my JSON uploaded anywhere?

No. Parsing and formatting run entirely in your browser tab.

Why do I get an error for single quotes or trailing commas?

Strict JSON requires double quotes and does not allow trailing commas or comments. JavaScript object literals are more relaxed than JSON.

Does formatting change my data?

No. Only whitespace changes. Very large integers beyond JavaScript's safe range may lose precision because the browser parses numbers as floating point.

Are keys re-ordered?

No. Keys keep their original order, except that integer-like keys are listed first by JavaScript.

How large a file can I paste?

A few megabytes works on most devices. Very large inputs may slow your browser.
