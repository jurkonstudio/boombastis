PDF to Text

Pull the text out of a PDF to copy or save.

  1. Choose a PDF
  2. Extract text
  3. Copy or save TXT

About this tool

PDF to Text reads the text layer of a PDF and gives it back as plain text that you can copy, edit or search. It is quick for reports, articles and ebooks.

A scanned PDF is only pictures, so it has no text to extract. Such files need OCR, which this tool does not include.

How to use

  1. Choose the PDF.
  2. Tick the box if you want a separator line between pages.
  3. Press Extract text.
  4. Copy the text or download it as a .txt file.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

Why is the result empty?

The PDF is probably a scan or photo of paper. It contains pictures, not text, so OCR is needed.

Is the layout kept?

Text is returned in reading order as plain lines. Tables and columns may not keep their exact layout.

Can I extract text from only some pages?

Use Split PDF first to extract those pages, then run this tool.
