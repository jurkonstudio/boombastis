Privacy Policy

Last updated: 6 November 2026

Summary

Boombastis does not ask you to create an account, does not set cookies, and does not use analytics or advertising scripts at the time of writing. Files, passwords and text you enter into the tools are processed in your browser and are not sent to us.

Tools that stay on your device

Image Compressor, QR Code Generator, Password Generator, Password Strength Checker, Word Counter, Hash Generator, Browser Info, JSON Formatter, Base64, Case Converter and the Indonesian tools (Terbilang, Pace, THR, Age, Photo Compressor, JSON/CSV) all work locally. Nothing you type or select leaves your device.

Third-party requests

  • IP & DNS Checker: asks api64.ipify.org and ipwho.is for your public IP address, country and ISP, and sends the domain names you look up to Cloudflare DNS (cloudflare-dns.com) and Google DNS (dns.google). Those services see your IP address and the domain you query, under their own privacy policies.
  • QR Code Generator: loads a QR library from cdnjs.cloudflare.com. Cloudflare receives a normal web request (IP address, browser details) when the page loads.
  • Hosting: the site is served by GitHub Pages. GitHub may log visitor IP addresses as described in its own privacy statement. We do not receive that log data.

Data stored in your browser

To work offline, the site stores its own files in your browser cache through a service worker. This contains no personal data. You can remove it any time by clearing site data for boombastis.my.id in your browser settings.

Changes

If we ever add analytics, advertising or other services, we will update this page first and say what data they collect.
