About this tool

Split PDF cuts one document into several, pulls out the pages you need, or deletes pages you do not want. It is useful for sending a single chapter, separating an invoice from a bundle, or removing a blank page.

When more than one file is created, you get a ZIP with everything inside, plus separate downloads for each part when there are 12 or fewer.

How to use

  1. Choose the PDF file.
  2. Select what you want: ranges, extract, remove, every page, or fixed parts.
  3. For ranges, type page numbers such as 1-3, 5, 8-10 (use 8- for page 8 to the end).
  4. Press Split PDF and download the result.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

How do I write page ranges?

Separate parts with commas. 1-3 means pages 1 to 3, 5 means page 5 only, and 8- means page 8 to the last page.

What is the difference between ranges and extract?

Ranges creates one file for each range you type. Extract puts every page you type into one single new PDF.

Can I split a password-protected PDF?

Not directly. Remove the password first, then split it.
