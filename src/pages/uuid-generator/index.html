About this tool

A UUID is a 128-bit identifier that is practically unique, used as database keys, file names, session IDs and request IDs. Version 4 is fully random. Version 7 starts with the current time, so new IDs sort in creation order, which keeps database indexes fast.

IDs are created with your browser's cryptographically secure random generator and never leave your device.

How to use

  1. Choose v4 for random IDs or v7 for time-ordered IDs.
  2. Enter how many you need.
  3. Tick options such as uppercase or no hyphens.
  4. Press Generate, then Copy all.

Frequently asked questions

Is my file uploaded anywhere?

No. Everything runs inside your browser with JavaScript, so your files never leave your device and nothing is stored on a server.

Which version should I use?

v4 is the common default. Use v7 for database primary keys where sort order and index performance matter.

Can two UUIDs collide?

The chance is so small that it can be ignored in practice.

Are these secure for tokens?

They use secure randomness, but for secrets such as API keys or passwords use a dedicated generator with more entropy.
