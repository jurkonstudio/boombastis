# Boombastis

Free online tools for images, text, passwords, networking and privacy. Most tools run entirely
in the browser, so files and passwords are never uploaded. The IP & DNS checker is the exception:
it calls public APIs (ipify, ipwho.is, Cloudflare DNS and Google DNS).

Live site: https://boombastis.my.id (static HTML, hosted on GitHub Pages).

## Project structure (v2.0)

Static site, no framework. Pages are generated by a zero-dependency Node script, so the header, footer,
hreflang, sitemap and service worker stay consistent. The URLs are the same as before.

- `src/pages/**/index.html`: the content of each page (a `<!--meta {...}-->` header with title, description, JSON-LD and scripts, then the tool form, About and FAQ).
- `data/tools.json`: the tool catalog (name, description, icon, categories) used by the home page cards and footers.
- `scripts/build.mjs`: generates the HTML in the repo root, `sitemap.xml` and `sw.js`.
- `assets/`: `site.css` (all styles), `ui.js` (theme and menu), `home.js` (search, categories, favorites), one script per tool.
- `tests/check.mjs` (static checks) and `tests/smoke.py` (Playwright browser test).

Commands (run in a terminal such as a Codespace):

```
node scripts/build.mjs      # regenerate pages, sitemap.xml, sw.js
node tests/check.mjs        # links, titles, canonicals, JSON-LD, hreflang, sitemap, script ids
python3 tests/smoke.py      # needs: pip install playwright && playwright install chromium
```

Do not edit the generated `index.html` files in the root; edit `src/pages` or `data/tools.json` and rebuild.

## Adding a new tool

1. Create `src/pages/<slug>/index.html` (copy a similar one), and its script in `assets/`.
2. Add an entry to `data/tools.json` (slug, lang, cats, name, desc, svg icon).
3. Run `node scripts/build.mjs` and `node tests/check.mjs`. The nav, home card, footer, sitemap and service worker update by themselves.

## QR library (offline and security)

The QR page still loads its library from cdnjs. To serve it from this site (works offline, no third-party request), run once:

```
mkdir -p assets/vendor && curl -L -o assets/vendor/qrcode.min.js https://cdnjs.cloudflare.com/ajax/libs/qrcode-generator/1.4.4/qrcode.min.js
node scripts/build.mjs
```

The build detects the file, switches the page to the local copy, tightens the CSP and adds it to the offline cache.

## Offline use (PWA)

`sw.js` caches every page after the first visit, so returning visitors can open the tools without a
connection. Bump `VERSION` in `sw.js` and add new tool URLs to `PRECACHE` on every release.
The site is plain static files and can be served by any static web server (`python3 -m http.server`).
