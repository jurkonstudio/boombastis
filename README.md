# Boombastis

Free online tools that run entirely in the browser: image compressor, QR code generator,
password generator, word counter, IP & DNS checker, password strength checker, hash generator and browser info. Most tools run entirely in the browser; the IP & DNS checker calls public APIs (ipify, ipwho.is, Cloudflare and Google DNS).

Hosted on GitHub Pages at https://boombastis.my.id (single static `index.html`).
