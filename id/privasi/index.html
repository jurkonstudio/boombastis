Kebijakan Privasi

Terakhir diperbarui: 6 November 2026

Ringkasan

Boombastis tidak meminta Anda membuat akun, tidak memasang cookie, dan saat ini tidak memakai skrip analitik atau iklan. File, kata sandi, dan teks yang Anda masukkan diproses di browser dan tidak dikirim kepada kami.

Alat yang tetap di perangkat Anda

Image Compressor, QR Code Generator, Password Generator, Password Strength, Word Counter, Hash Generator, Browser Info, JSON Formatter, Base64, Case Converter, dan alat berbahasa Indonesia (Terbilang, Pace, THR, Umur, Kompres Foto, JSON/CSV) bekerja secara lokal. Apa pun yang Anda ketik atau pilih tidak meninggalkan perangkat.

Permintaan ke pihak ketiga

  • IP & DNS Checker: meminta api64.ipify.org dan ipwho.is untuk alamat IP publik, negara, dan ISP Anda, serta mengirim nama domain yang Anda cari ke Cloudflare DNS (cloudflare-dns.com) dan Google DNS (dns.google). Layanan itu melihat alamat IP dan domain yang Anda cari, sesuai kebijakan privasi masing-masing.
  • QR Code Generator: memuat pustaka QR dari cdnjs.cloudflare.com. Cloudflare menerima permintaan web biasa (alamat IP, detail browser) saat halaman dimuat.
  • Hosting: situs disajikan oleh GitHub Pages. GitHub dapat mencatat alamat IP pengunjung sesuai kebijakannya sendiri. Kami tidak menerima data log tersebut.

Data yang disimpan di browser

Agar bisa dipakai offline, situs menyimpan file miliknya sendiri di cache browser lewat service worker. Isinya tidak berisi data pribadi. Anda bisa menghapusnya kapan saja dengan menghapus data situs boombastis.my.id di pengaturan browser.

Perubahan

Jika suatu saat kami menambahkan analitik, iklan, atau layanan lain, halaman ini diperbarui lebih dulu dan menjelaskan data apa yang dikumpulkan.
